# plates/incoming -- the owner's generated plates, bytes by hash

The library's manifest (asset-generators plates/manifest.json) cites a plate by its sha256 and never holds the bytes (its CHARTER). The bytes live here, in the owner's own repository, named by the first 16 hex of the hash and the subject, and the manifest's hint is this file's raw URL. Every plate here is generated by the owner with Google Nano Banana (no copyright claim) unless its manifest entry says otherwise.
